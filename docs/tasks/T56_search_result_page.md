# T56. 상품/가게 검색 결과 화면 구현

- 상태:
  완료

- GitHub Issue:
  194

- 우선순위:
  P2

- 선행 조건:
  - 선행 task: T05 (상품 목록 할인율 필터/정렬 DB pagination 복구), T12 (공개 상품 목록 Server Component 초기 데이터 전환)

- 분류:
  화면/UI

- 사용자 흐름:
  Consumer

- 주 담당 역할:
  Frontend

- 보조 역할:
  API

- 배경:
  IA 정합성 확인 중 `/search` 경로가 미구현 상태임을 확인했다. PRD C-PROD-05 요구사항에 해당한다. GNB 검색 버튼이 존재하지만 결과 화면이 없다.

- 문제:
  상품명/가게명으로 검색했을 때 결과를 보여주는 화면이 없다.

- 작업 내용:
  - `/search` 페이지 구현
  - 검색어 query parameter 처리 (`?q=...`)
  - 상품/가게 검색 결과 표시 (탭 분리 또는 통합)
  - 검색 결과 없음 상태 처리
  - 비로그인 접근 허용

- 관련 파일/영역:
  - `src/app/(consumer)/search/` 또는 `src/app/search/`
  - `src/api/products/` (검색 파라미터 지원)
  - `src/api/stores/` (가게 검색 지원)

- 예상 난이도:
  보통

- 완료 기준:
  - `/search?q=키워드`로 접근 시 상품/가게 검색 결과가 표시된다.
  - 검색 결과가 없을 때 빈 상태 UI를 보여준다.

- 확인 필요 사항:
  - 상품 검색과 가게 검색을 분리할지 통합할지
  - 검색 API 엔드포인트 현재 구현 상태
  - 검색 결과 정렬 기준
