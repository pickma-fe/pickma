# T70. 알림 센터 UI 구현

- 상태:
  진행 전

- GitHub Issue:
  확인 필요

- 우선순위:
  P3

- 선행 조건:
  - 선행 task: T22. 실시간 알림 기반 설계 및 1차 구현

- 분류:
  기능

- 사용자 흐름:
  Consumer / Seller

- 주 담당 역할:
  Shared-FE

- 보조 역할:
  Consumer-FE, Seller-FE

- 배경:
  T22에서 Toast 기반 실시간 알림 인프라가 구축됐다. Toast는 일시적으로 표시되고 사라지기 때문에 놓친 알림을 다시 확인할 방법이 없다. 헤더에 알림 아이콘과 알림 목록 컴포넌트를 추가해 알림을 모아볼 수 있게 한다.

- 문제:
  Toast 알림은 화면에 잠깐 표시되고 사라져 사용자가 놓칠 수 있다. 알림을 다시 확인할 수 있는 진입점이 없다.

- 작업 내용:
  - 헤더에 알림 벨 아이콘 버튼을 추가한다.
  - 아이콘 클릭 시 알림 목록 패널(드롭다운 또는 슬라이드 패널)을 표시한다.
  - 알림 목록 컴포넌트를 구현한다.
  - 알림 히스토리 저장 방식을 결정한다 (예: Toast store 확장, 별도 Zustand store, 또는 `notifications` 테이블 신규 생성 여부).
  - 읽음/안읽음 처리 정책을 결정하고 구현한다.
  - 비로그인 상태에서는 아이콘을 표시하지 않는다.

- 관련 파일/영역:
  - `src/components/common/Toast/` (Toast 인프라)
  - `src/components/common/Notification/` (신규)
  - `src/stores/` (알림 히스토리 store)
  - 헤더 컴포넌트

- 예상 난이도:
  중간

- 완료 기준:
  - 헤더에 알림 아이콘이 표시된다.
  - 아이콘 클릭 시 알림 목록 패널이 열린다.
  - 실시간으로 수신된 알림이 목록에 쌓인다.
  - 읽음/안읽음 처리가 동작한다.
