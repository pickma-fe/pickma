# PickMa 법적 준수 요건

PickMa 서비스 운영에 적용되는 한국 법률 의무와 구현 목록을 정리한다.
실제 개인정보처리방침·이용약관 문구는 T42에서 작성한다.

---

## 1. 적용 법률

### 개인정보보호법 (PIPA)

| 조항   | 내용                                        | PickMa 적용                        |
| ------ | ------------------------------------------- | ---------------------------------- |
| 제15조 | 개인정보 수집·이용 시 정보주체 동의 필요    | 회원가입, 판매자 서류 제출 동의    |
| 제21조 | 처리목적 달성 후 지체 없이 파기             | Storage 보관 기간 정책 (섹션 13.3) |
| 제22조 | 동의 받는 방법: 필수/선택 구분, 명시적 동의 | 가입 동의 체크박스 구분            |
| 제23조 | 민감정보 처리 시 별도 동의                  | 신분증 사본 등 서류 제출 동의      |
| 제24조 | 고유식별정보(주민번호 등) 처리 제한         | 신분증 사본 취급 기준              |
| 제30조 | 개인정보처리방침 수립·공개 의무             | `/privacy-policy` 페이지           |

### 전자상거래 등에서의 소비자보호에 관한 법률 (전상법)

| 조항         | 내용                    | PickMa 적용                                |
| ------------ | ----------------------- | ------------------------------------------ |
| 제10조       | 이용약관 작성·명시 의무 | `/terms` 페이지                            |
| 시행령 제6조 | 거래 기록 보관 기간     | 계약·청약철회 5년, 결제·공급 5년, 분쟁 3년 |

### 전자금융거래법

| 조항   | 내용                   | PickMa 적용                                   |
| ------ | ---------------------- | --------------------------------------------- |
| 제22조 | 금융거래 기록 5년 보관 | Toss 지급대행 범위 내 — Toss 계약서 확인 필요 |

## 2. 법적 의무 구현 체크리스트

### 공개 의무

- [ ] 개인정보처리방침 수립 및 `/privacy-policy` 공개 (PIPA 제30조) → **T42**
- [ ] 이용약관 `/terms` 공개 (전상법 제10조) → **T42**
- [ ] Footer에 두 페이지 링크 노출 → **T42**

### 동의 수집 의무

- [ ] 회원가입 시 개인정보 수집·이용 동의 (PIPA 제15조, 제22조) → **T42**
  - 필수: 서비스 제공 목적 (이름, 이메일, 연락처)
  - 선택: 마케팅 수신 (별도 독립 체크박스)
- [ ] 회원가입 시 이용약관 동의 (필수) → **T42**
- [ ] 판매자 신청 서류 제출 단계에서 민감정보·고유식별정보 별도 동의 (PIPA 제23조, 제24조) → **T42**
  - 신분증 사본, 통장 사본에 해당
  - 일반 개인정보 동의와 별도 독립 체크박스로 구분 필수

### 파기 의무

- [ ] Storage orphan cleanup API + hook 구현 (PIPA 제21조) → **T40**
- [ ] Storage 주기적 orphan 스캔 (PIPA 제21조) → **T41**
- 보관 기간 정책 상세: `docs/system_architecture.md` 섹션 13.3

## 3. 개인정보처리방침 필수 항목

T42에서 `/privacy-policy` 페이지 구현 시 아래 항목이 포함되어야 한다.

1. **수집하는 개인정보 항목**
   - 일반 회원: 이름, 이메일, 연락처
   - 판매자: 위 항목 + 신분증 사본, 통장 사본, 사업장 정보

2. **수집 및 이용 목적**
   - 서비스 제공, 본인 확인, 판매자 자격 심사, 결제 처리

3. **보유 및 이용 기간**
   - 판매자 서류: 활동 기간 보관, 자격 종료 후 30일 이내 삭제
   - 거부된 서류: 거부 확정 후 30일 이내 삭제
   - 회원 탈퇴 시 서류: 30일 이내 삭제
   - 거래 기록: 전상법 기준 5년 (계약·결제), 3년 (분쟁)
   - 상세: `docs/system_architecture.md` 섹션 13.3

4. **개인정보의 제3자 제공**
   - Toss Payments: 결제 처리 목적 (결제 금액, 주문 정보)

5. **개인정보 처리 위탁**
   - Supabase: DB 및 Storage 인프라
   - Vercel: 서버 호스팅
   - Toss Payments: 결제 처리

6. **정보주체의 권리**
   - 열람, 정정, 삭제, 처리 정지 요구권
   - 행사 방법: 고객센터 또는 이메일 접수

7. **개인정보 보호책임자**
   - 담당자 정보 (운영팀 지정 필요)

## 4. 미결 / 재검토 필요 항목

- **Toss KYC 의무 범위**: PickMa가 신분증 사본을 직접 보관해야 하는지, Toss가 KYC 주체인지 Toss 계약서에서 확인 필요. 확인 결과에 따라 `docs/system_architecture.md` 섹션 13.5 재검토.
- **신분증 원본 처리 개선**: 고유식별정보(주민번호) 마스킹 처리 또는 PASS·휴대폰 인증 등 대체 방식 검토 필요 → issue draft: `temp/issues/backend/seller-document-id-masking.md`
- **개인정보 보호책임자 지정**: 처리방침 작성 전 담당자 확정 필요 (운영 결정).
